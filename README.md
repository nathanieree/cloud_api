# 🌦️ PokeSpotiWeather — Multi-API Web App

A Python Flask web application that combines **three external APIs** — Pokémon, Spotify, and OpenWeather — into one unified and interactive experience.


## 🛠️ Tech Stack
- **Back-End:** Python, Flask
- **APIs:** PokéAPI, Spotify Web API, OpenWeatherMap API
- **Front-End:** HTML, CSS, JavaScript

## 💡 What It Does
Search for a Pokémon, a city's weather, and a mood-based Spotify playlist — all from one web app. The app fetches and combines data from three different REST APIs and presents it in a clean, unified UI.

## ✨ Features
- 🎮 Pokémon lookup via PokéAPI (stats, types, abilities)
- 🌤️ Real-time weather data by city via OpenWeatherMap
- 🎵 Spotify playlist recommendations based on weather mood
- Combined single-page experience
